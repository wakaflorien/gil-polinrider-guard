Gil-Polinrider-Guard

Scan a git repository for PolinRider IOCs before you clone it onto your machine.

Scanners to run: all · none
Select at least one scanner.
Token is sent once for this scan only, never stored or logged.
Under Docker Compose, enter "/scan" to scan whatever SCAN_PATH points at (defaults to the project directory).
"Scan all repos" treats the path as a parent folder and scans every git repository found under it.

Recovery

Strip known IOC lines from this repo's entire git history, without destroying legitimate work committed on top. Works on a disposable copy — the directory you scanned is never modified directly. If you don't also enable force-push below, the rewrite is verified then discarded (nothing persists to push later); check that box to actually publish the fix, or use scripts/surgical_clean.py from the CLI for full manual control over the resulting mirror clone.

This creates a disposable mirror clone of the repo and rewrites history there via git-filter-repo. The directory you scanned is not touched.
This overwrites the remote's history. Every collaborator's local clone will diverge and need to be re-cloned. This cannot be undone.
Edits .vscode/tasks.json directly in the directory you scanned, removing only the risky task(s) found and leaving any other tasks in the file untouched. This rewrites the file's JSON structure, so comments (if any) are lost and formatting is normalized. It's a normal working-tree change — if the file is tracked, git checkout -- .vscode/tasks.json undoes it.
